# 日報・週報を作る

## このスキルでできること

その日・その週にやったことのメモを渡すと、
**報告書の形**に整理します。

## 使い方

やったことを箇条書きで書いて、こう伝えます。

```
これを週報にして
```

順不同のメモで大丈夫です。時系列に並んでいなくても整理します。

## 手順

1. 渡されたメモから、やったことを拾う
2. **結果（数字）が書かれているもの**を見つけて分ける
3. うまくいかなかったことを拾う
4. 次にやることを整理する
5. 決められた形式で出力する

## 最重要のルール

**やったことの羅列で終わらせない。そして、盛らない。**

報告書が「やったことリスト」で終わると、読む人（自分を含む）が
次に何をすべきか判断できません。必ず結果と次の一手をセットにします。

同時に、次のことを守ってください。

- **数字を作らない。** メモに書かれていない数値は書かない
- **うまくいかなかったことを省かない。** メモにあれば必ず載せる
- **成果を大きく見せる言い換えをしない。**
  「3件問い合わせ」を「複数の反響」と書き換えない

うまくいかなかったことが載っていない報告書は、
翌週も同じ失敗を繰り返す原因になります。

## 出力形式

```markdown
# ◯月◯日〜◯月◯日 週報

## やったこと
- （実施した内容）

## 結果
- （数字で言えるもの。メモにある範囲で）

## うまくいかなかったこと
- （つまずいた点、進まなかったこと）

## 次にやること
- （次の期間に着手すること）

## 相談したいこと
- （判断が必要な点。なければ省略）
```

日報の場合は見出しを「◯月◯日 日報」に変え、内容は同じ構成にしてください。

## 例

**入力されたメモ：**

```
月 インスタ投稿3本
火 問い合わせ2件、うち1件は返信まだ
水 新メニューの説明文を書いた、まだ公開してない
木 打ち合わせ1件（来月から開始で合意）
金 経理まとめようとしたけど手つかず
```

**出力：**

```markdown
# 週報

## やったこと
- Instagram投稿 3本
- 新メニューの説明文を作成（未公開）
- 打ち合わせ 1件

## 結果
- 問い合わせ 2件
- 打ち合わせ1件が来月開始で合意

## うまくいかなかったこと
- 問い合わせ1件が未返信のまま
- 新メニューの説明文が未公開
- 経理の整理に着手できなかった

## 次にやること
- 未返信の問い合わせに返信する
- 新メニューを公開する
- 経理の整理に着手する
```

「経理が手つかず」を省かず、そのまま「次にやること」に送っている点が大切です。

## うまく使うコツ

- 毎日メモを1行残しておくと、週末に貼り付けるだけで週報になります
- 提出先がある場合は「上司に出す形で」と伝えると、調子が変わります
- 「相談したいこと」は、自分ひとりで事業をしている場合でも書いておくと、後で判断を思い出せます
