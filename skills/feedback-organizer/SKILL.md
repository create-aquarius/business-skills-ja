# アンケート・お客様の声の整理

## このスキルでできること

バラバラに集まったアンケート回答や感想を、
**満足している点・不満な点・要望・その他**に分類して一覧にします。

## 使い方

回答をまとめて貼り付けて、こう伝えます。

```
このアンケートを整理して
```

1件ずつでも、コピペした塊でも、表形式でもかまいません。

## 手順

1. 全件を読み、それぞれを4つに分類する
2. **原文をそのまま**引用して並べる
3. 分類ごとの件数を数える
4. 複数の人が同じことを言っている場合は、その旨を書き添える

## 最重要のルール

**お客様の言葉を言い換えない。要約しない。**

これが最も大切な点です。

「思っていたより全然わかりやすくて、これなら続けられそうです」を
「高評価」とまとめてしまうと、**その声はもう使えなくなります**。

お客様の声は、言葉そのものが価値です。
分類はしても、**一字一句そのまま**残してください。

長い回答でも、途中を省略せずに全文を残します。
どうしても長い場合は省略記号を使い、勝手に短くまとめないでください。

## 分類の基準

| 分類 | 入れるもの |
|---|---|
| 満足している点 | 良かった、助かった、期待以上だった、という内容 |
| 不満な点 | わかりにくい、期待と違った、困った、という内容 |
| 要望 | 「〜してほしい」「〜があれば」という次への希望 |
| その他 | 上記に当てはまらないもの。質問、近況報告など |

1件の回答に複数の要素が入っている場合は、**該当する分類すべてに載せて**かまいません。

## 個人情報の扱い

回答に次のものが含まれていたら、整理結果の最後に指摘してください。

- 氏名、会社名、店舗名
- メールアドレス、電話番号
- 本人が特定できる具体的な状況

**お客様の声を販売ページなどに掲載する場合は、本人の許可が必要です。**
このスキルは整理をするだけで、掲載の可否は判断しません。

## 出力形式

```markdown
## 全体
回答数：◯件

## 満足している点（◯件）
- 「（原文のまま）」
- 「（原文のまま）」

## 不満な点（◯件）
- 「（原文のまま）」

## 要望（◯件）
- 「（原文のまま）」

## その他（◯件）
- 「（原文のまま）」

## 複数の方が触れていた点
- （同じ趣旨の声が複数あった場合のみ記載）

## 注意
- （個人情報が含まれる場合はここに記載）
```

## うまく使うコツ

- Googleフォームやアンケートツールからコピペしたまま渡せます
- 「不満な点だけ抜き出して」と絞ることもできます
- 「複数の方が触れていた点」は、次の改善の優先順位を決める材料になります
