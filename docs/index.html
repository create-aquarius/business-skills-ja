このガイドについて

この特典は、AIに「この仕事はこう進めてね」という手順書を覚えさせておくためのものです。

たとえば打ち合わせのメモを渡すと、決まったこと・やること・保留に分けて整理してくれます。 毎回長い指示を書く必要がなくなります。

使うのは、ふだんお使いのChatGPTやClaudeで大丈夫です。 新しくアプリを入れたり、会員登録をしたりする必要はありません。

使い方は3ステップ

  1. 下の一覧から「GitHubで開く」を押す 使いたいものを1つ選んでください。手順書のページが開きます。
  2. 開いたページで、手順書をコピーする コピーのしかたは、このあとの「GitHubでのコピーのしかた」で説明しています。
  3. ChatGPT・Claude・Codexのいずれかに貼り付けて、自分のメモを貼る 新しい会話に貼り付けて送信し、つづけて整理したいメモを貼るだけです。

スキル一覧（ここからコピー）

使いたいものの「GitHubで開く」を押してください。手順書の全文が読めます。

打ち合わせメモを整理する

走り書きや録音の文字起こしを、「決まったこと」「やること」「保留」「確認が必要なこと」の4つに分けます。

GitHubで開く meeting-notes-to-actions

記事をSNS・メルマガに転用する

一本の記事から、X・Instagram・メルマガそれぞれに合った形を作ります。

GitHubで開く content-repurposing

アンケート・お客様の声を整理する

バラバラの回答を、お客様の言葉そのままで、満足点・不満点・要望に分類します。

GitHubで開く feedback-organizer

問い合わせの返信を下書きする

金額や納期はわざと空欄で残すので、あいまいな約束がそのまま送られる心配がありません。

GitHubで開く inquiry-reply-draft

商品・サービスの説明文を作る

一言・短め・詳しめの3つの長さで作ります。効果を保証するような表現は避けます。

GitHubで開く service-description

競合を調べてメモにする

他社のページを、比較できる形に整理します。事実と推測をきちんと分けます。

GitHubで開く competitor-research-notes

日報・週報を作る

バラバラのメモから、結果と次の一手が入った報告書にします。

GitHubで開く weekly-report
ご注意

一度に貼り付けるのは1つだけにしてください。いくつも貼ると指示が混ざって、うまく動かなくなります。

別のことをしたくなったら、新しい会話を開いて貼り直してください。

GitHubでのコピーのしかた

「GitHubで開く」を押すと、SKILL.md という手順書のページが開きます。 「Preview」のままで大丈夫です。 ページ上部にある、ファイル全体をコピーするボタンを使います。

パソコンの場合

  1. ページ上部の「Raw」を探す

    「Preview」「Code」「Blame」と並んでいる欄の右側に、「Raw」というボタンがあります。

  2. 「Raw」の右隣にあるコピーアイコンを押す

    四角が2つ重なったアイコンです。押すと、手順書の全文がコピーされます。

  3. 「Copied!」と表示されたら完了

    画面の見た目はほとんど変わりません。「Copied!」と表示されれば、コピーできています。

スマートフォンの場合

  1. 「Preview」「Code」「Blame」の右端にある「…」を押す

    ファイル名の少し下にある、3つの点のボタンです。

  2. 「Raw file content」の「Copy」を押す

    これで手順書の全文がコピーされます。「Copied!」と表示されたら完了です。

ChatGPT・Claude・Codexのいずれかに貼り付ける

ChatGPT・Claude・Codexのいずれかで新しい会話を開き、コピーした内容を貼り付けて送信してください。 つづけて、整理したいメモや文章を貼れば使えます。

対応しているAI： このページで使い方を案内しているのは、ChatGPT・Claude・Codexです。 すべてのAIサービスでの動作を保証するものではありません。

「Code」に切り替える必要はありません。 ページ本文の途中にも小さなコピーボタンがありますが、そこでは一部分しかコピーされません。 必ずページ上部の「Raw」の近くにあるコピー機能を使ってください。

やってみましょう

「打ち合わせメモを整理する」を例に、実際の流れを見てみます。

自分が貼ったメモ
  • 田中さんとの打ち合わせ
  • 新サイトの公開は来月アタマで合意
  • トップの写真、差し替えたいと言われた→誰が用意する？
  • 料金プラン、3つに増やす案が出たけど保留
  • 請求書の宛名、法人名でいいか要確認
返ってきたもの
決まったこと
  • 新サイトの公開時期は来月頭とする
やること
  • トップページの写真を差し替える（担当：未定／期限：未定）
保留・次回持ち越し
  • 料金プランを3つに増やす案
確認が必要なこと
  • トップ写真の素材を用意するのはどちらか
  • 請求書の宛名を法人名にしてよいか

写真の担当者は、メモに書かれていないので「未定」と出ます。 AIが勝手に「田中さんが用意する」と決めないように作ってあります。

議事録は後から「言った・言わない」の証拠になる書類です。 それらしく埋まってしまうと、書類として使えなくなるためです。

毎回貼らずに使う

気に入って何度も使うようになったら、AIに覚えさせておくことができます。 一度登録すれば、貼り付けなしで「このメモ整理して」と言うだけで動きます。

お使いのものに合わせて、以下をお読みください。

ChatGPT（アプリ・ブラウザ）

  1. スキルの画面を開く

    左側の「プラグイン」を開き、画面上部の「スキル」を選びます。

  2. チャットで作成する

    「作成」から「チャットで作成」を選び、コピーした中身を貼り付けます。「この内容を変えずにスキルとして作成してください。書かれていない内容は足さないでください」と伝え、画面の案内に従って確認します。

  3. 話しかける

    「このメモ整理して」と伝えて、メモを貼れば動きます。

ご注意

複数のスキルを登録するときも、1つずつ作成してください。画面の名称や場所は、ご利用のプランや時期によって変わる場合があります。

Codex（アプリ・ブラウザ・ターミナル）

Codexは、アプリでもブラウザでもターミナルでも、同じスキルがそのまま使えます。 スキルの追加画面から、各スキルの「GitHubで見る」のURLを指定するか、コピーした中身を貼り付けてください。

ターミナルをお使いの場合は、次のコマンドで7つまとめて入ります。

Windows PowerShell：

npx.cmd skills add create-aquarius/business-skills-ja -a codex

Mac・Linux：

npx skills add create-aquarius/business-skills-ja -a codex

Claude（ブラウザ）

「プロジェクト」を作って、その説明欄に貼り付けて保存してください。 以降、そのプロジェクトの中では貼り付けなしで使えます。

Claude Code

次のコマンドで7つまとめて入ります。

Windows PowerShell：

npx.cmd skills add create-aquarius/business-skills-ja -a claude-code

Mac・Linux：

npx skills add create-aquarius/business-skills-ja -a claude-code

Windowsで「running scripts is disabled」と表示された場合も、実行ポリシーは変更せず npx.cmd をお使いください。

スキルの画面が見当たらない場合もあります。その場合は、これまでどおり貼り付けてお使いください。動作に違いはありません。

よくある質問

無料のChatGPTでも使えますか

使えます。貼り付けて使う方法なら、プランは問いません。

コピーのアイコンが見つかりません

「Preview」から「Code」に切り替えると表示されます。それでも見つからない場合は、表示されている文章を全部選択してコピーしてください。同じものが使えます。

7つ全部を一度に貼り付けてもいいですか

おすすめしません。指示が混ざって精度が落ちます。1つの会話につき1つにしてください。

出てきた文章はそのまま使っていいですか

必ずご自身で確認してからお使いください。特に、お客様に送るメールや、販売ページの文章は必ず読み返してください。

問い合わせ返信のスキルは、金額や納期をわざと空欄にして「【要確認：金額】」と出すように作ってあります。そこはご自身で埋めてから送ってください。

自分用に書き換えてもいいですか

はい。自由に書き換えてお使いください。自社の料金表やサービス内容を書き足すと、精度が上がります。

うまくいかないときは

思ったような形で出てこない

貼り付けた文章が、途中で切れていないか確認してください。いちばん上の線で囲まれた部分から、いちばん下まで全部が必要です。

別のことをされてしまう

新しい会話を開いて、もう一度貼り付けてください。同じ会話で長く続けると、前の話に引っ張られることがあります。

途中から言うことを聞かなくなった

会話が長くなると起こります。新しい会話を開いて、貼り直してください。

GitHubで公開しています

このスキル集は、どなたでも自由に使える形で公開しています。 中身の確認も、自分用の書き換えも、再配布も自由です。

★（スター）について

GitHubのページ右上にある★を押すと、このスキル集が「使われているもの」として表示されるようになります。 同じことで困っている方に見つけてもらいやすくなるので、役に立ったら押していただけると助かります。 アカウントをお持ちであれば、クリック一回で終わります。
