# はじめてのAIスキル集 ── 使い方ガイド

## このガイドについて

この特典は、**AIに「この仕事はこう進めてね」という手順書を覚えさせておく**ためのファイル集です。

一度用意しておけば、毎回長い指示を書かなくても、
「このメモ整理して」の一言で、決まった形に仕上がるようになります。

パソコンの専門知識は必要ありません。
コピーして貼り付けるだけで使えます。

---

## 入っているもの（全7種類）

| ファイル名 | できること |
|---|---|
| meeting-notes-to-actions | 打ち合わせメモを、決定事項・やること・保留・要確認に整理する |
| content-repurposing | 長い記事を、X・Instagram・メルマガ向けに書き分ける |
| feedback-organizer | アンケートやお客様の声を、原文のまま分類して一覧にする |
| inquiry-reply-draft | 問い合わせへの返信を下書きする |
| service-description | 商品・サービスの説明文を3つの長さで作る |
| competitor-research-notes | 競合ページを比較できるメモにする |
| weekly-report | バラバラのメモから日報・週報を作る |

## どのAIで使えるか

| お使いのもの | 使えるか | 方法 |
|---|---|---|
| ChatGPT | 使えます | スキルとして登録する |
| Claude（ブラウザ版） | 使えます | プロジェクトに登録する |
| Claude Code | 自動で動きます | インストール |
| Codex | 自動で動きます | インストール |

**ChatGPTをお使いの方が最も多いと思いますので、まずその方法から説明します。**

---

## 方法1：ChatGPTに登録して使う

ChatGPTには「スキル」を登録しておく機能があります。
一度登録すれば、毎回貼り付ける必要はありません。

### 手順

**1. ファイルをダウンロードする**

配布ページから、使いたいスキルの `SKILL.md` ファイルを保存します。

**2. ChatGPTのスキル画面を開く**

左側のメニューから「スキル（Skills）」を開きます。

**3. 追加する**

「新規作成」または「＋」から追加します。
**パソコンからファイルをアップロードする**方法と、
**エディタに直接貼り付ける**方法のどちらでも登録できます。

ファイルをアップロードする場合は、保存した `SKILL.md` をそのまま選んでください。

**4. 使ってみる**

登録したら、普通に話しかけるだけです。

```
このメモ整理して
```

と伝えて、続けてメモを貼り付ければ動きます。

### 注意

**パソコン版とスマホ版は別々に登録が必要です。**
自動では同期されないため、両方でお使いの場合はそれぞれ登録してください。

### スキル機能が見当たらない場合

ご利用のプランや時期によっては、スキル画面が表示されないことがあります。
その場合は、貼り付けて使ってください。動作に違いはありません。

1. `SKILL.md` の中身を、上から下まですべてコピーする
2. 新しいチャットに貼り付ける
3. その下に「この手順に従ってください。準備ができたら『どうぞ』とだけ返してください」と書く
4. 「どうぞ」と返ってきたら、自分のメモを貼る

## 方法3：Claude Code で使う（自動で動きます）

ターミナルを使える方は、こちらのほうが快適です。
一度入れておけば、貼り付けの必要すらなくなります。

### まとめて7つ入れる

ターミナルで次のコマンドを実行してください。

```
npx skills add create-aquarius/business-skills-ja -a claude-code
```

### 1つだけ入れる

```
npx skills add create-aquarius/business-skills-ja --skill meeting-notes-to-actions -a claude-code
```

### 使いかた

インストール後は、普通に話しかけるだけです。

```
このメモ整理して
```

と伝えれば、対応するスキルが自動で選ばれます。
ファイルを貼り付ける必要はありません。

---

## 方法4：Codex で使う

Claude Codeと同じコマンドで、末尾だけ変えます。

```
npx skills add create-aquarius/business-skills-ja -a codex
```

## やってみましょう

`meeting-notes-to-actions` を例に、実際の流れを見てみます。

**貼り付けるメモ：**

```
田中さんとの打ち合わせ
・新サイトの公開は来月アタマで合意
・トップの写真、差し替えたいと言われた→誰が用意する？
・料金プラン、3つに増やす案が出たけど保留
・請求書の宛名、法人名でいいか要確認
```

**返ってくるもの：**

```
## 決まったこと
- 新サイトの公開時期は来月頭とする

## やること
| 内容 | 担当 | 期限 |
|---|---|---|
| トップページの写真を差し替える | 未定 | 未定 |

## 保留・次回持ち越し
- 料金プランを3つに増やす案

## 確認が必要なこと
- トップ写真の素材を用意するのはどちらか
- 請求書の宛名を法人名にしてよいか
```

写真の担当者は、メモに書かれていないので「未定」と出ます。
**AIが勝手に「田中さんが用意する」と決めない**ように作ってあります。

議事録は後から「言った・言わない」の証拠になる書類です。
それらしく埋まってしまうと、書類として使えなくなるためです。

## よくある質問

**Q. スキルの登録画面が見つかりません**

ご利用のプランや時期によっては、表示されないことがあります。
その場合は貼り付けて使ってください。動作に違いはありません。

**Q. 7つ全部を一度に貼り付けてもいいですか**

おすすめしません。指示が混ざって精度が落ちます。
**1つの会話につき1つのスキル**にしてください。

**Q. 出てきた文章はそのまま使っていいですか**

**必ずご自身で確認してから**お使いください。
特に、お客様に送るメールや、販売ページの文章は必ず読み返してください。

`inquiry-reply-draft`（問い合わせ返信）は、金額や納期を**わざと空欄**にして
`【要確認：金額】` と出すように作ってあります。
そこはご自身で埋めてから送ってください。

**Q. 自分用に書き換えてもいいですか**

はい。自由に書き換えてお使いください。
自社の料金表やサービス内容を書き足すと、精度が上がります。

---

## うまくいかないときは

**思ったような形で出てこない**

貼り付けたスキルの中身が、途中で切れていないか確認してください。
`---` で囲まれた冒頭部分から、いちばん下まで全部が必要です。

**別のことをされてしまう**

新しい会話を開いて、もう一度貼り付けてください。
同じ会話で長く続けると、前の話に引っ張られることがあります。

**スキルが選ばれない（Claude Code・Codex）**

「このメモ整理して」のように、やってほしいことを短く伝えてください。
ファイル名で呼び出す必要はありません。
